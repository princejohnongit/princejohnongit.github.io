# 👑 princejohnongit.github.io

My personal portfolio website — a comprehensive showcase of who I am, what I build, and where I'm headed.

**🔗 Live:** [princejohnongit.github.io](https://princejohnongit.github.io)

## ✨ Features

- **Animated Hero** with particle constellation background and typing effect
- **Project Showcase** linking to all major GitHub repositories
- **Interactive Timeline** for professional experience
- **Skills Grid** organized by category with hover effects
- **Hackathon Highlights** with achievement badges
- **Certifications & Education** section
- **Responsive Design** — looks great on all devices
- **Glassmorphism UI** with smooth micro-animations

## 🛠 Tech Stack

- Pure HTML5, CSS3 & Vanilla JavaScript
- Google Fonts (Space Grotesk + Inter)
- Canvas API for particle animation
- IntersectionObserver for scroll reveals
- Hosted on GitHub Pages

## 📂 Structure

```
├── index.html   # Main portfolio page
├── style.css    # Design system & responsive styles
├── script.js    # Animations & interactivity
└── README.md    # This file
```

## 🚀 Deploy

This site is automatically deployed via GitHub Pages from the `main` branch. Simply push to deploy.
